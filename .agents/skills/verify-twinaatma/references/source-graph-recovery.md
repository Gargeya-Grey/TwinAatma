Use Python 3.11+ from the trusted checkout. Each command creates complete task-owned
toolkit copies, a synthetic identity and isolated gate state beneath its unique run.

```powershell
python -B .agents/skills/verify-twinaatma/scripts/graph.py --output work/gc-artifacts/.knowledgeos/graph-proof
python -B .agents/skills/verify-twinaatma/scripts/recovery.py --journey index --output work/gc-artifacts/.knowledgeos/recovery-index

```

Run `recovery.py --journey write-faults` separately on native POSIX with a fresh
contained output. It uses a real file-size limit to cause partial marker writes.
An unsupported filesystem or unavailable runtime remains NOT CHECKED.

Graph requires all sixteen cases: literal local/parent/root paths, anchors and
labels, fenced and absent targets, ambiguous basenames, incoming and two-hop
relations, live edits and moves, source preservation and stopped processes. The
persistent MCP must disclose both ambiguous candidates without inventing an edge.
Warning scope follows sources expanded within the requested hops. Anchor resolution
proves the note path; heading existence and frontmatter aliases are outside this
producer's scope.

Index recovery has six cases: missing/corrupt index, real SQLite contention,
rebuild contention, and blocked rebuild/manifest paths. Current quotes, removed-note
filtering, explicit incompleteness and autonomous retry must agree with source bytes.
Unsafe SQLite database/sidecar links and nonplain paths must remain preserved and
refused; they are not ordinary corrupt caches to quarantine.

Ownership needs fifteen ordinary cases across index, gate and session locks plus
all three native partial-write cases. Retain actual live holders, aged markers,
contenders, holder tokens, dead-owner recovery, foreign replacement bytes and retry
results. Production ownership timeouts stay unchanged. A live holder's age never
authorizes stealing its lock. Raw cache/guard bytes unreadable under a Windows lock
are explicitly labeled; source files still require complete before/after hashes.
