complete toolkit copy. It can prove only the existing `LEARNING.decision_views`
and `LEARNING.attributed_lessons` source outcomes.

From the trusted checkout, use Python 3.11 or newer:

```powershell
python -X utf8 -B .agents/skills/verify-twinaatma/scripts/learning.py --output work/gc-artifacts/.knowledgeos/source-learning
```

membership; combined status/outcome filters; external edits while a real SQLite

completed source, identify the source path and explicitly limit the claim to one
recorded outcome. No approval endpoint or owner command runs in this journey.
