## Preconditions

Place generated fixture subtrees below a .knowledgeos component that the note census excludes. Use a unique synthetic vault and isolated `KNOWLEDGEOS_STATE_DIR`. Preserve current uncommitted work. Source-only scripts often bind their vault to the checkout rather than `--vault`; exercise them only in a complete task-owned copy after inspecting their path resolution.

## Evidence rules

An unrun entry point stays NOT CHECKED even if another entry point passed. A missing capability is FAIL when tested against its specified outcome. An unavailable external prerequisite is BLOCKED or NOT CHECKED, with the reason.

The helper checks a narrow deterministic subset and always reports `ideal_system_verdict: NOT CHECKED`. Read [the ideal-system contract](../references/ideal-system.md) for the complete acceptance conditions. Read [the dated assessment](../references/current-assessment.md) for observed starting conditions.

Every repair proof batch also emits the fixed-denominator [acceptance score](../references/acceptance-scoring.md). Missing proof remains unresolved.
